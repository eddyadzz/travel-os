# BoliFlow Travel OS — Sales Deck

Slide-by-slide outline. Each section maps to one slide (or a short sequence).
Run the **demo environment** (`/deploy` → Load demo data) alongside for a live walkthrough.

## 1 · Title
- **BoliFlow Travel OS** — The operating system for a travel agency.
- Subtitle: One platform for sales, operations, suppliers, finance and your website.
- Tagline: *Lead → Quote → Acceptance → Booking → Travel → Accounting.*

## 2 · The problem
How agencies operate today:
- **Excel** for availability and rates
- **WhatsApp & email** for enquiries and confirmations
- **Manual supplier follow-up** (spreadsheets, chasing)
- **Manual quotations** rebuilt every time
- Fragmented: the website, the inbox, the ledger and the suppliers never talk to each other.

## 3 · The solution
**BoliFlow Travel OS** — a complete travel business operating system:
- Public website + instant quotes that **feed the CRM automatically**
- A booking engine, customer portal and supplier portal on one database
- Automation that runs reminders, supplier follow-ups and arrivals
- Finance, forecasting and reporting built in

## 4 · Customer journey (live demo)
```
Search → Property → Instant quote → Accept online → Booking → Deposit → Vouchers → Travel
```
Show: destination pages, stays directory, availability search, the property page
"Get a quote", the quote acceptance portal, the booking portal, arrival emails.

## 5 · Supplier journey (live demo)
```
Supplier portal → Availability → Rates → Blackouts → Promotions → Updates
```
Show: supplier login, the availability grid, scorecards (response time, reliability),
and the automation that stops chasing slow suppliers.

## 6 · Finance journey (live demo)
```
Booking → Payment → Profit → Accounting
```
Show: P&L with gross margin, outstanding balances, deposits, agent commissions,
and one-click Xero / QuickBooks journal export.

## 7 · Reporting & intelligence
- **Command center** — expected revenue, overdue deposits, arrivals, contracts renewing, agent performance at a glance
- **Forecasting** — revenue, collections and profit projections
- **Supplier scorecards** — reliability ranked automatically
- **AI assistant** — answers questions, ranks leads, drafts follow-ups

## 8 · Automation
- Scheduled jobs run the platform: deposit reminders, balance reminders, supplier
  escalations, arrival sequences (T-7 / T-3 / T-1 vouchers), daily reports
- Full job history, retries and failure alerts

## 9 · Website & branding
- The website **is** the booking engine — CMS, destination pages, content pages
- Each deployment carries the client's **own brand**: logo, colors, typography,
  domain and email identity

## 10 · Deployment model
- **Single-client deployment** — dedicated server + database
- Client-owned **branding** and **domain**
- No shared multi-tenant infrastructure
- Repeatable onboarding: guided wizard, import templates, readiness check, backup + restore

## 11 · Support & security
- Deployment toolkit, backup/restore with verification, diagnostics bundle
- Audit trail on every change
- PWA — installable mobile experience for agents and customers
