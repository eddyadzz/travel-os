# Pricing Framework

A reference model for pricing BoliFlow deployments. Adjust figures to your market.
The principle: a predictable **one-time setup** + **annual support** keeps the client
relationship clean, and **optional services** monetize the work beyond the core.

## 1 · One-time setup fee

| Item | Included | Suggested range |
|------|----------|-----------------|
| Server provisioning + deployment | Dedicated VPS, Docker stack, domain + SSL | $1,000 – $2,500 |
| Data import | Properties, rooms, rates, suppliers, customers, leads | $500 – $1,500 |
| Branding & configuration | Logo, colors, typography, email, custom domain | $500 – $1,000 |
| Supplier onboarding | Portal links + training for each partner | $250 – $500 |
| Staff training | Admin + agents + owner session | $500 – $1,000 |
| **Total setup** | | **$2,750 – $6,500** |

## 2 · Annual support

Covers updates, backups, monitoring and support. Charge annually, in advance.

| Tier | Includes | Suggested |
|------|----------|-----------|
| **Standard** | Updates, automatic backups + verification, monitoring, job alerts, email support | $1,500 – $3,000 / year |
| **Priority** | Standard + same-day response, quarterly health review, off-hours support | $3,000 – $5,000 / year |

## 3 · Optional services (priced per engagement)

| Service | Suggested |
|---------|-----------|
| Website design (beyond the included CMS theme) | $1,000 – $3,000 |
| Property data entry (catalogue build-out) | $15 – $40 per property |
| Supplier integration (API channel connector + mapping) | $1,500 – $4,000 per supplier |
| Custom development (per module / integration) | $120 – $200 / hour |
| Content writing (destination guides, blog, SEO pages) | $100 – $300 per page |
| Demo environment setup (for the client's own sales demos) | $500 |

## 4 · Discounting & packaging

- **Package** the setup + first year of Standard support into a single "deployment" price.
- Offer a **pilot discount** for the first client in a new market or niche.
- **Annual prepay** discount (e.g., 5–10%).
- Never discount support below cost of backups + monitoring + updates.

## 5 · What the fee covers, mapped to the platform

| Fee | Platform capability |
|-----|---------------------|
| Setup | `/onboard` wizard, `/deploy` readiness, import templates |
| Support | `/jobs`, `/automation`, `/deploy` support toolkit + diagnostics |
| Updates | `scripts/update.sh`, schema sync |
| Backups | `/deploy` backup + verification, `scripts/backup.sh` |
| Supplier integration | `/connectors` channel framework + room mapping |

## 6 · Renewal & value story

Annual support renews at the same rate. Emphasise the value in the renewal:
automation removes manual follow-up, forecasting improves decisions, and the
readiness/backup tooling protects the client's data — all running without their
involvement.
